# IT Help Desk Troubleshooting Checklist

## Purpose
This checklist provides a structured approach for IT Help Desk technicians to diagnose, resolve, verify, and document common technical issues reported by users.

## 1. Initial Issue Assessment

- [ ] Record the user's name and contact details.
- [ ] Identify the affected device or application.
- [ ] Understand the reported problem.
- [ ] Ask when the issue started.
- [ ] Identify any recent changes to the system.
- [ ] Record any error messages or screenshots.
- [ ] Determine whether the issue affects one user or multiple users.
- [ ] Assess the impact and urgency of the issue.

## 2. Basic Troubleshooting

- [ ] Check power, cables, and physical connections.
- [ ] Confirm network connectivity.
- [ ] Restart the affected application if appropriate.
- [ ] Restart the device if appropriate and approved.
- [ ] Check whether the issue can be reproduced.
- [ ] Verify user credentials and account status where relevant.
- [ ] Check application or system updates.
- [ ] Review available error messages and logs.

## 3. Issue-Specific Checks

### Network Issues
- [ ] Check Wi-Fi or Ethernet connection.
- [ ] Verify IP address configuration.
- [ ] Test connectivity using `ping`.
- [ ] Check DNS resolution.
- [ ] Verify VPN connection if required.

### Email Issues
- [ ] Verify internet connectivity.
- [ ] Check mailbox storage.
- [ ] Confirm account credentials.
- [ ] Check Outlook status and configuration.
- [ ] Test sending and receiving emails.

### Hardware Issues
- [ ] Check device power.
- [ ] Inspect cables and connections.
- [ ] Verify device status.
- [ ] Check drivers where applicable.
- [ ] Test using another port or peripheral if available.

### Performance Issues
- [ ] Check CPU and memory usage.
- [ ] Review available disk space.
- [ ] Identify unnecessary background applications.
- [ ] Check for pending updates.
- [ ] Restart the system if appropriate.

### Account Issues
- [ ] Verify user identity according to policy.
- [ ] Check account lockout status.
- [ ] Verify password expiration.
- [ ] Check account permissions.
- [ ] Follow approved password reset procedures.

## 4. Resolution and Verification

- [ ] Apply the appropriate solution.
- [ ] Confirm the issue is resolved.
- [ ] Ask the user to verify functionality.
- [ ] Ensure no additional issues occurred.
- [ ] Record the solution and outcome.

## 5. Documentation and Escalation

- [ ] Document troubleshooting steps performed.
- [ ] Record error messages and findings.
- [ ] Update the ticket or incident record.
- [ ] Escalate if the issue remains unresolved.
- [ ] Include all relevant information in the escalation.
- [ ] Inform the user about the status.

## Troubleshooting Workflow

1. Identify the issue.
2. Gather information.
3. Diagnose possible causes.
4. Perform troubleshooting.
5. Apply a solution.
6. Verify resolution.
7. Document the outcome.
8. Escalate if required.

## Important Reminders

- Follow organizational security policies.
- Do not make unauthorized configuration changes.
- Protect user data and confidentiality.
- Communicate clearly and professionally.
- Escalate critical or unresolved issues promptly.

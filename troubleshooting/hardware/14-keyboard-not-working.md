# Keyboard Not Working

## 1. Problem Description
The user is unable to type using the keyboard. The keyboard may not respond at all, certain keys may fail, or input may stop working intermittently.

## 2. Symptoms
- Keyboard does not respond to typing.
- Some keys are unresponsive.
- Keyboard disconnects intermittently.
- Keyboard works on the login screen but not after login.
- Wireless keyboard fails to connect.

## 3. Possible Causes
- Loose USB connection.
- Low battery in a wireless keyboard.
- Bluetooth connectivity problems.
- Keyboard driver issues.
- Physical damage or faulty keys.
- Accessibility settings affecting keyboard input.

## 4. Diagnostic Steps
1. Check whether the keyboard is physically connected.
2. Test another USB port if using a wired keyboard.
3. Check battery levels if the keyboard is wireless.
4. Test the keyboard on another computer, if available.
5. Check whether the issue affects all keys or only specific keys.
6. Determine whether the keyboard works before Windows login.

## 5. Solutions
1. Disconnect and reconnect the keyboard.
2. Replace batteries or recharge the wireless keyboard.
3. For Bluetooth keyboards, remove and pair the device again.
4. Restart the computer.
5. Check Windows Accessibility settings and disable Filter Keys if enabled unintentionally.
6. Open Device Manager and check for keyboard driver warnings.
7. Update or reinstall the keyboard driver if necessary and authorized.
8. Replace the keyboard if hardware failure is confirmed.

## 6. Verification
- Confirm that all required keys respond correctly.
- Test typing in Notepad or another text editor.
- Verify that the keyboard remains connected.
- Confirm that the issue does not return after restarting.

## 7. Prevention
- Keep keyboards clean and avoid liquid spills.
- Replace wireless batteries when needed.
- Avoid pulling cables forcefully.
- Keep device drivers updated.

## 8. Escalation
Escalate to IT support if the keyboard remains unresponsive after connection, battery, and driver checks. Include the device type, connection method, affected keys, and troubleshooting performed.

# Printer Not Printing

## 1. Problem Description
The user is unable to print documents from their computer. The printer may appear connected but does not produce printed output, or print jobs remain stuck in the queue.

## 2. Symptoms
- Documents are not printing.
- Print jobs remain pending or stuck.
- Printer displays an error message.
- Printer appears offline.
- Printing works from one application but not another.

## 3. Possible Causes
- Printer is powered off or disconnected.
- Network or USB connection issues.
- Incorrect printer selected.
- Print queue is blocked.
- Printer is out of paper or ink/toner.
- Printer driver issues.
- Print spooler service malfunction.

## 4. Diagnostic Steps
1. Check whether the printer is powered on and displays a ready status.
2. Verify that paper is loaded and ink or toner is sufficient.
3. Confirm that the correct printer is selected.
4. Check the printer connection (USB or network).
5. Print a test page directly from the printer settings.
6. Check whether multiple documents are stuck in the print queue.

## 5. Solutions
1. Restart the printer and the user's computer.
2. Verify or reconnect the USB cable or network connection.
3. Set the correct printer as the default printer if required.
4. Open the print queue and cancel stuck print jobs.
5. Run the Windows printer troubleshooter, if available.
6. If the issue persists, restart the Print Spooler service if authorized:
   - Press `Win + R`.
   - Type `services.msc`.
   - Locate **Print Spooler**.
   - Right-click and select **Restart**.
7. Update or reinstall the printer driver with IT support if necessary.

## 6. Verification
- Print a Windows test page successfully.
- Print a document from the user's application.
- Confirm the print queue clears normally.
- Verify that the printer is available for future print jobs.

## 7. Prevention
- Keep printer drivers updated.
- Check paper and toner levels regularly.
- Avoid sending repeated print jobs when the printer is unresponsive.
- Maintain stable network connectivity for network printers.

## 8. Escalation
Escalate to IT support if the printer remains unavailable after basic troubleshooting. Include the printer model, connection type, error message, affected users, and troubleshooting steps already performed.

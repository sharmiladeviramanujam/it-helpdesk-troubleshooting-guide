# Applications Crashing

## 1. Problem Description
An application unexpectedly closes, freezes, or stops responding during use. The issue may occur occasionally or repeatedly and can interrupt the user's work.

## 2. Symptoms
- Application closes without warning.
- Application displays an error message.
- Application freezes and stops responding.
- User loses unsaved work.
- The same application crashes repeatedly.

## 3. Possible Causes
- Software bugs or compatibility issues.
- Outdated application version.
- Corrupted application files.
- Insufficient system resources.
- Conflicting background applications.
- Damaged user profile or configuration settings.

## 4. Diagnostic Steps
1. Record the application name and version.
2. Identify the task being performed when the crash occurred.
3. Check whether the issue affects one user or multiple users.
4. Restart the application and attempt to reproduce the issue.
5. Check whether other applications are also crashing.
6. Note any error messages or codes displayed.

## 5. Solutions
1. Close the application completely and reopen it.
2. Restart the computer if the application continues to crash.
3. Install available application updates.
4. Close unnecessary applications to free system resources.
5. If available, use the application's repair option through Windows Settings → Apps → Installed apps.
6. Clear application cache only when supported and approved.
7. If the problem started after an update, report the issue to IT support for compatibility review.
8. Reinstall the application if approved and other troubleshooting steps fail.

## 6. Verification
- Open the application successfully.
- Perform the task that previously caused the crash.
- Confirm that the application remains stable.
- Verify that no recurring error messages appear.

## 7. Prevention
- Keep applications updated.
- Save work regularly.
- Avoid installing unauthorized software.
- Maintain sufficient system resources.
- Report recurring application errors promptly.

## 8. Escalation
Escalate to IT support if the application continues crashing after troubleshooting. Provide the application name, version, error message, crash frequency, affected users, and steps to reproduce the issue.

# High CPU Usage

## 1. Problem Description
The computer experiences high CPU utilization, causing applications to respond slowly, system lag, excessive fan noise, or reduced overall performance.

## 2. Symptoms
- Computer becomes slow or unresponsive.
- Applications take longer to open.
- CPU usage remains unusually high.
- Cooling fans run continuously.
- System performance decreases during multitasking.

## 3. Possible Causes
- Resource-intensive applications.
- Too many applications running simultaneously.
- Background updates or scans.
- Startup applications consuming resources.
- Malware or suspicious processes.
- Software bugs or outdated applications.

## 4. Diagnostic Steps
1. Open Task Manager using `Ctrl + Shift + Esc`.
2. Select the Processes tab.
3. Click the CPU column to sort processes by usage.
4. Identify applications consuming unusually high CPU resources.
5. Check whether CPU usage remains high when idle.
6. Determine whether the issue started after installing or updating software.

## 5. Solutions
1. Close unnecessary applications.
2. Restart the computer to clear temporary processes.
3. If an application is unresponsive, end the task only after checking for unsaved work.
4. Disable unnecessary startup applications through Task Manager.
5. Allow Windows updates and background scans to complete.
6. Update applications that consistently cause high CPU usage.
7. Run a security scan using approved antivirus software if suspicious processes are identified.
8. Escalate recurring issues for further performance analysis.

## 6. Verification
- CPU usage decreases to a normal level when idle.
- Applications respond more quickly.
- System fan noise decreases when appropriate.
- The computer operates normally during routine tasks.

## 7. Prevention
- Avoid running unnecessary applications simultaneously.
- Review startup applications regularly.
- Keep Windows and applications updated.
- Perform regular security scans.
- Monitor resource usage when performance issues occur.

## 8. Escalation
Escalate to IT support if CPU usage remains consistently high without an identifiable cause. Include the affected applications, CPU utilization observations, system specifications, and troubleshooting steps performed.

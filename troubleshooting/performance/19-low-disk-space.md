# Low Disk Space

## 1. Problem Description
The user's computer is running low on available storage space. This may prevent applications from installing, files from being saved, Windows updates from completing, or the system from operating efficiently.

## 2. Symptoms
- Low disk space warning appears.
- Unable to download or save files.
- Windows updates fail.
- Applications run slowly or fail to install.
- The storage drive shows very little free space.

## 3. Possible Causes
- Large files stored on the system drive.
- Temporary files and cached data.
- Recycle Bin contains deleted files.
- Too many applications installed.
- Old Windows update files.
- Duplicate or unnecessary files.

## 4. Diagnostic Steps
1. Open File Explorer and select This PC.
2. Check the available free space on the system drive.
3. Identify which drive is running low on storage.
4. Review Downloads, Desktop, Documents, and Videos folders.
5. Check whether temporary files are consuming significant space.
6. Identify large applications or files that may no longer be required.

## 5. Solutions
1. Empty the Recycle Bin after confirming its contents are no longer needed.
2. Delete unnecessary files from the Downloads folder.
3. Open Windows Settings → System → Storage.
4. Review Temporary files and remove appropriate items.
5. Use Storage Sense to clean up unnecessary files if available.
6. Uninstall unused applications through Settings → Apps.
7. Move personal files to an approved storage location, such as an authorized external drive or company cloud storage.
8. Do not delete system files or company data without authorization.

## 6. Verification
- Confirm that available disk space has increased.
- Verify that applications open and operate normally.
- Confirm that files can be saved successfully.
- Check whether Windows updates can proceed.

## 7. Prevention
- Review disk space periodically.
- Remove unnecessary downloads and temporary files.
- Avoid storing large personal files on company devices.
- Use approved cloud or network storage for large files.
- Enable Storage Sense where permitted.

## 8. Escalation
Escalate to IT support if the disk continues filling up unexpectedly or if storage cleanup does not resolve the issue. Include the drive affected, available storage, warning messages, and troubleshooting steps performed.

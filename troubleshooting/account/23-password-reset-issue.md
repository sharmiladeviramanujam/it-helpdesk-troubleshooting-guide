# Password Reset Issue

## 1. Problem Description
The user is unable to reset their password using the password recovery process. The reset request may fail, the reset email may not arrive, or the reset link may expire before use.

## 2. Symptoms
- Password reset request fails.
- Reset email is not received.
- Reset link displays an error or has expired.
- New password is rejected.
- User cannot sign in after resetting the password.

## 3. Possible Causes
- Incorrect registered email address.
- Reset email delayed or filtered into spam.
- Expired or previously used reset link.
- Password does not meet complexity requirements.
- Temporary password recovery service issue.
- Account is locked or restricted.

## 4. Diagnostic Steps
1. Confirm the user is accessing the official password reset page.
2. Verify that the correct account identifier is entered.
3. Check the spam or junk email folder for the reset message.
4. Confirm whether the reset email was received.
5. Check whether the reset link is expired or already used.
6. Review the password requirements displayed on the reset page.
7. Determine whether other users are experiencing the same issue.

## 5. Solutions
1. Retry the password reset using the correct account information.
2. Check the spam, junk, and other email folders.
3. Request a new reset link if the previous link has expired.
4. Open the latest reset link and avoid using older reset emails.
5. Create a password that meets the organization's password requirements.
6. If the reset email is not received, contact IT support to verify the registered account and recovery options.
7. If the account is locked or restricted, request assistance from the authorized administrator.

## 6. Verification
- Confirm that the password reset completes successfully.
- Sign in using the new password.
- Verify access to required applications.
- Confirm that no additional reset errors appear.

## 7. Prevention
- Keep recovery email addresses and contact information updated.
- Use strong passwords that meet security requirements.
- Avoid sharing reset links.
- Request a new reset link rather than repeatedly using an expired one.
- Use only official password recovery pages.

## 8. Escalation
Escalate to IT support if password recovery remains unsuccessful. Include the affected service, error message, time of request, whether the reset email arrived, and troubleshooting steps performed. Never include passwords or reset links in support tickets.

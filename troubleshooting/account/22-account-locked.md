# Account Locked

## 1. Problem Description
The user's account has been locked after multiple unsuccessful sign-in attempts. The user cannot access company resources until the account is unlocked or the lockout condition is resolved.

## 2. Symptoms
- Login displays an account locked message.
- User cannot access email or company applications.
- Authentication attempts are rejected.
- Account repeatedly becomes locked after being unlocked.
- User receives unexpected sign-in notifications.

## 3. Possible Causes
- Incorrect password entered multiple times.
- Old credentials saved on another device.
- Applications repeatedly attempting authentication with outdated passwords.
- Password stored in a mobile device, browser, or service.
- Suspicious sign-in activity.
- Account security policy triggered a lockout.

## 4. Diagnostic Steps
1. Confirm the exact account lockout message.
2. Ask whether the user recently changed their password.
3. Determine whether the lockout affects Windows, email, VPN, or other applications.
4. Check whether the user is signed in on other devices.
5. Identify whether the account becomes locked again after being unlocked.
6. Check for unexpected login activity if security tools are available.

## 5. Solutions
1. Stop repeated login attempts to prevent further lockouts.
2. Verify the user's identity according to company procedures.
3. Contact the authorized IT administrator to check the account lockout status.
4. Request an account unlock through the approved administrative process.
5. If the password was recently changed, update saved credentials on authorized devices and applications.
6. Sign out of devices or applications that may be repeatedly using outdated credentials.
7. If suspicious activity is detected, follow the organization's security incident process.

## 6. Verification
- Confirm the account is unlocked.
- Verify the user can sign in successfully.
- Check access to required applications.
- Confirm the account does not become locked again.
- Verify that suspicious authentication activity has been addressed.

## 7. Prevention
- Use the correct password and approved password manager.
- Update saved credentials after password changes.
- Avoid repeated login attempts.
- Sign out of unused devices.
- Report unexpected account lockouts promptly.

## 8. Escalation
Escalate to IT support or the security team if the account repeatedly locks or suspicious sign-in activity is identified. Include the affected service, time of lockout, error message, and relevant observations. Never request or share passwords or MFA codes.

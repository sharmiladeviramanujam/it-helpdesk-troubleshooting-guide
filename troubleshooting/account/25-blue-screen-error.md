# Blue Screen Error (BSOD)

## 1. Problem Description
The computer unexpectedly displays a blue screen with an error message or stop code and restarts or shuts down. The issue may occur occasionally or repeatedly, preventing the user from working normally.

## 2. Symptoms
- Blue screen appears unexpectedly.
- Computer restarts automatically.
- Stop code or error message is displayed.
- System crashes during startup.
- Crashes occur while using specific applications.
- Computer becomes unstable after a driver or Windows update.

## 3. Possible Causes
- Faulty or incompatible device drivers.
- Windows system file corruption.
- Hardware problems involving RAM or storage.
- Overheating.
- Recent software or hardware changes.
- Failed Windows updates.

## 4. Diagnostic Steps
1. Record the stop code displayed on the blue screen.
2. Note when the crash occurs, such as during startup, while using an application, or during normal operation.
3. Check whether the issue began after a recent software, driver, or hardware change.
4. Determine whether the computer restarts successfully.
5. Check whether the issue occurs repeatedly or only once.
6. Review Windows reliability history for recent system failures, if available.

## 5. Solutions
1. Restart the computer and check whether Windows loads normally.
2. Disconnect unnecessary external devices and check whether the issue persists.
3. If the problem began after a driver update, contact IT support to review or roll back the driver if appropriate.
4. Install approved Windows updates if the computer is stable.
5. Run Windows system file checks through IT-approved troubleshooting procedures.
6. Check for overheating, blocked ventilation, or unusual fan behavior.
7. If the system cannot start normally, escalate for recovery or startup troubleshooting.
8. Avoid opening the device or replacing internal components unless authorized.

## 6. Verification
- Confirm the computer starts successfully.
- Verify that the blue screen does not recur during normal use.
- Test the applications that were running when the crash occurred.
- Confirm that the system is stable after troubleshooting.

## 7. Prevention
- Keep Windows and device drivers updated through approved channels.
- Avoid installing unauthorized software.
- Maintain proper ventilation.
- Safely disconnect external devices.
- Save work regularly.
- Report repeated system crashes promptly.

## 8. Escalation
Escalate to IT support if blue screen errors continue or the computer cannot boot. Provide the stop code, crash frequency, device model, recent changes, and troubleshooting steps performed.


# Wi-Fi Not Connecting

## 1. Problem Description
The user is unable to connect their computer to an available wireless network.

## 2. Symptoms
- Wi-Fi network is not visible.
- Connection fails repeatedly.
- Windows displays "Can't connect to this network".
- Wi-Fi shows as disconnected.

## 3. Possible Causes
- Wi-Fi adapter is disabled.
- Incorrect wireless password.
- Router or access point issue.
- Outdated network driver.
- Incorrect network configuration.

## 4. Diagnostic Steps
1. Check whether Wi-Fi is enabled.
2. Check whether other devices can connect.
3. Open Windows Command Prompt.
4. Run `ipconfig /all`.
5. Check the wireless adapter status.
6. If connected, test connectivity using `ping 8.8.8.8`.

## 5. Solutions
1. Enable the Wi-Fi adapter.
2. Verify the wireless password.
3. Restart the computer.
4. Forget the wireless network and reconnect.
5. Check for an updated network driver through approved Windows Update procedures.
6. Contact the network administrator if the issue persists.

## 6. Verification
- Confirm Wi-Fi shows Connected.
- Open a website.
- Confirm internet connectivity.

## 7. Prevention
- Keep network drivers updated.
- Use correct network credentials.
- Report recurring connectivity problems.

## 8. Escalation
Escalate to the network administrator if the issue remains unresolved.

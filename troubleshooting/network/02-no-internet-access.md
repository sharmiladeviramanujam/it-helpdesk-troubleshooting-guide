# No Internet Access

## 1. Problem Description
The user is connected to a Wi-Fi or Ethernet network but cannot access the internet or online services.

## 2. Symptoms
- Browser displays "No Internet Connection".
- Websites are not loading.
- Applications cannot connect to online services.
- Network icon shows limited connectivity.
- Internet access is unavailable despite being connected to Wi-Fi.

## 3. Possible Causes
- Router or modem connectivity issue.
- Incorrect IP address configuration.
- DNS resolution failure.
- Internet Service Provider (ISP) outage.
- Network adapter issue.
- Proxy configuration problem.

## 4. Diagnostic Steps
1. Check whether other devices connected to the same network have internet access.
2. Verify that Wi-Fi or Ethernet is connected.
3. Open Command Prompt.
4. Run `ipconfig` to check the IP address and default gateway.
5. Run `ping` followed by the default gateway address to test local network connectivity.
6. Run `ping 8.8.8.8` to test external IP connectivity.
7. Run `nslookup google.com` to check DNS resolution.
8. Check whether an internet outage has been reported.

## 5. Solutions
1. Disconnect and reconnect to the network.
2. Restart the computer if appropriate.
3. Restart the router only if authorized.
4. Check network adapter status.
5. Verify proxy settings with IT support.
6. Contact the network administrator or ISP if the issue persists.

## 6. Verification
- Confirm the device is connected to the network.
- Verify internet connectivity using a ping test.
- Open websites in a browser.
- Confirm online applications are functioning correctly.

## 7. Prevention
- Report recurring network connectivity issues.
- Avoid unauthorized changes to network settings.
- Keep network drivers updated through approved procedures.
- Monitor network outage notifications.

## 8. Escalation
Escalate to the network support team if internet connectivity remains unavailable after basic troubleshooting. Include diagnostic results, error messages, and affected devices.

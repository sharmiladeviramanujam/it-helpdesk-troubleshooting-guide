# Outlook Search Not Working

## 1. Problem Description
Users are unable to find emails using the Outlook search feature. Search results may be missing, incomplete, outdated, or show no results even when the emails exist in the mailbox.

## 2. Symptoms
- Outlook search returns no results.
- Recent emails do not appear in search results.
- Search results are incomplete.
- Searching for a sender or subject does not find matching emails.
- Search works in Outlook Web but not in the desktop application.

## 3. Possible Causes
- Incorrect search keywords or filters.
- Search limited to the current folder.
- Outlook search index is incomplete or corrupted.
- Search indexing is still in progress.
- Outlook application issues.
- Cached mailbox data is outdated.

## 4. Diagnostic Steps
1. Search using a simple keyword from a known email subject.
2. Check whether the search scope is set to the current folder or all mailboxes.
3. Remove any active filters that may restrict search results.
4. Compare search results between Outlook Desktop and Outlook Web.
5. Check whether recently received emails appear when searching.
6. If using Outlook Desktop, verify whether indexing is complete.

## 5. Solutions
1. Change the search scope to **All Mailboxes** or **All Outlook Items**, where available.
2. Clear search filters and try different keywords.
3. Restart Outlook and perform the search again.
4. If Outlook Desktop search is incomplete, check Windows indexing settings:
   - Open Control Panel.
   - Select **Indexing Options**.
   - Confirm Microsoft Outlook is included, if available.
   - Check the indexing status.
5. If indexing is incomplete or corrupted, rebuild the search index if permitted by IT support.
6. Install pending Office updates if the issue persists.

## 6. Verification
- Search for a known email using its subject or sender.
- Confirm that older and recent emails appear in the results.
- Verify that search works across multiple folders.
- Compare the results with Outlook Web when available.

## 7. Prevention
- Use meaningful email subjects.
- Avoid unnecessary search filters.
- Keep Outlook updated.
- Allow indexing to complete after mailbox changes or Office updates.

## 8. Escalation
Escalate to the IT support team if search continues to return incomplete results after checking search scope, filters, and indexing. Include the Outlook version, affected mailbox, example search keywords, and screenshots of the issue.
